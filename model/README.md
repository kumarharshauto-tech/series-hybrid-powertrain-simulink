\# Simulink Model



The original MATLAB/Simulink model developed during this project is not currently included in the public repository.



The available development model contains external data-file dependencies and parameters from different stages of the design process. Publishing it in its current form could therefore make the model difficult to reproduce from a fresh clone.



A cleaned and reproducible version is planned for a future update.



\## Planned Model Improvements



Before publication, the Simulink model will be updated to:



\- Replace absolute file paths with repository-relative paths

\- Consolidate the final vehicle and component parameters

\- Include the required WLTP and lookup-table data

\- Organise motor, generator, engine and battery parameters consistently

\- Verify subsystem connections and controller settings

\- Test the model from a clean MATLAB/Simulink environment



The current repository therefore focuses on the modelling methodology, engineering calculations and selected simulation results generated during the project.
